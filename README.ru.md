# EchoSign Attest

> **Криптографическая аттестация аудио** (целостность и provenance).
> Это **не** сертифицированный детектор дипфейков и **не** судебная экспертиза.

[English](README.md) · [中文](README.zh.md) · [Threat model](docs/THREAT_MODEL.md)

## Что доказываем

1. Целостность байтов после подписания (Ed25519)
2. Существование во времени (TSA / OpenTimestamps — в развитии)
3. Авторство = контроль закрытого ключа
4. Цепочка хранения proof-пакетов

**Не заявляем:** «живой человек vs ИИ», отраслевые сертификации, телефонию, судебную экспертизу.

## Быстрый старт

```bash
cp .env.example .env
npm install && npm test && npm run dev
```
