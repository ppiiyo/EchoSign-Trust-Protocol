## 🎯 1. Для чего нужен проект?

**EchoSign Voice Inspector** — это комплексный программный комплекс информационной безопасности и фоноскопической экспертизы. Он предназначен для оперативной проверки подлинности речи, мгновенного выявления клонированных нейросетями голосов (TTS, Deepfakes, Voice Changers), защиты аудиозаписей неслышимыми водяными знаками и отражения атак телефонного мошенничества (вишинга) в реальном времени.

С появлением генеративных моделей речи (ElevenLabs, XTTS-v2, VITS, HiFi-GAN, DiffSinger) человеческий слух потерял способность распознавать синтез. EchoSign объединяет **цифровую обработку сигналов (DSP)**, **физическую биометрию голосовых связок человека**, **потоковый анализ телефонных звонков**, **экспертный ИИ-анализ** и **криптографию** в единую платформу.

## ⚡ 2. Какие проблемы решает

| Проблема | Сценарий атаки / Риск | Решение EchoSign |
| :--- | :--- | :--- |
| **Клонирование голоса руководства (CEO Fraud / Вишинг)** | Злоумышленники звонят в бухгалтерию голосом директора и требуют срочно перевести средства. | **SIP/RTP Шлюз и SOC Дашборд**: Перехват и анализ звукового потока с задержкой до 200 мс и автоматическим сбросом звонка. |
| **Фальсификация судебных аудиоулик и монтаж** | Вставка сгенерированных фраз или удаление слов из аудиозаписей допросов и телефонных переговоров. | **Диаризация и шкала фазовых склеек**: Точный поиск границ склейки с микросекундной точностью и анализом фазового дрифта. |
| **Нелегальный парсинг голосов дикторов** | Скачивание записей актеров дубляжа и дикторов для обучения генеративных AI-моделей. | **Психоакустические водяные знаки DSSS+QIM**: Внедрение неслышимых защитных метаданных (1.8–4.6 кГц), выдерживающих сжатие MP3 и телефонию. |
| **Ложные срабатывания на студийном вокале** | Автотюн (Auto-Tune / Melodyne) принимается наивными детекторами за синтетический дипфейк. | **Гибридный ансамбль 4 векторов**: Отделяет квантование по музыкальной хроматической сетке от фазового шума диффузионных нейросетей. |

## 🚀 3. Полная матрица возможностей (Версия v4.1)

### 🔍 Ядро детекции и биометрия связок
- **Комплексная оценка физики голоса**: Детекция основного тона ($F_0$), джиттера ($<1.04\%$), шиммера ($<3.8\%$), соотношения гармоник к шуму HNR ($>15\text{ дБ}$) и фазовых артефактов нейросетевых вокодеров.
- **Запись и загрузка**: Мгновенный захват с микрофона браузера или загрузка аудиофайлов (WAV, MP3, M4A, FLAC, OGG).

### 📄 Судебно-акустические отчёты PDF с ЭЦП
- Генерация официального судебного экспертного заключения с расчетом всех физических параметров, криптографическим SHA-256 хешем исходного файла и процедурным QR-кодом для моментальной онлайн-валидации.

### 👥 Диаризация спикеров и таймлайн склеек
- Автоматическое разделение аудиопотока по отдельным дикторам (Спикер 1 / 2 / 3).
- Интерактивная временная шкала с подсветкой подозрительных стыков, аномально коротких пауз ($<40\text{ мс}$) и фазовых разрывов.

### 🔑 Личный кабинет разработчика & API-ключи
- Управление боевыми (`echosign_live_...`) и тестовыми (`echosign_test_...`) API-ключами.
- Настройка скоупов разрешений (`verify:audio`, `watermark:embed`, `telephony:stream`, `soc:admin`) и готовые примеры кода на cURL, Python, Node.js и Go.

### 📞 REST API v2 & Вебхуки (Webhooks)
- Отправка уведомлений в реальном времени с криптографической подписью HMAC-SHA256 в заголовке `X-EchoSign-Signature`.
- Поддержка событий `voice.deepfake_detected`, `watermark.extracted`, `call.spoofing_alert` с автоматическими повторными попытками доставки.

### 🧩 Браузерное расширение (Google Meet / Telegram / WhatsApp)
- Симулятор работы расширения прямо в веб-интерфейсах **Google Meet**, **Telegram Web**, **WhatsApp Web** и **YouTube**.
- Скачивание готового пакета Manifest v3 для внедрения в корпоративный браузер сотрудников.

### 📊 SOC Дашборд для службы кибербезопасности
- Лента инцидентов телефонного мошенничества и попыток взлома биометрии в реальном времени.
- Тепловая карта атакуемых подразделений (Топ-менеджмент, Бухгалтерия, Клиентский сервис) и кнопка мгновенной изоляции/блокировки звонящего.

### 🎙️ SIP/RTP Шлюз реального времени (Asterisk, Cisco, Avaya)
- Потоковый анализатор акустических фреймов со скользящим окном 200 мс.
- Поддержка кодеков G.711u, Opus HD и AMR-WB, задержка детекции менее 200 мс и автоматический разрыв соединения при атаке.

### 📦 On-Premise и автономное развертывание (Docker / K8s)
- Готовые конфигурации `Dockerfile`, `docker-compose.yml` и Helm-чарты для развертывания в закрытом банковском периметре (Air-Gapped).
- Интерактивный калькулятор сайзинга серверов (CPU, RAM, GPU).

### 🛡️ Соответствие стандартам (ГОСТ Р 52633, ISO 27001, SOC 2)
- Интерактивная матрица аудита по стандартам **ГОСТ Р 52633.5** (Защита биометрии от атак подделки), **ISO/IEC 27001**, **SOC 2 Type II** и **EU AI Act**.
- Генерация и печать официального аттестата соответствия ИБ.

## 💻 5. Пошаговая инструкция по запуску

### Системные требования
- **Node.js**: `v20.0.0` или выше
- **npm**, **bun**, **yarn** или **pnpm**

### Установка и запуск

1. **Клонирование репозитория**:
   ```bash
   git clone https://github.com/your-org/echosign-voice-inspector.git
   cd echosign-voice-inspector
   ```

2. **Установка зависимостей**:
   ```bash
   npm install
   ```

3. **Настройка переменных окружения**:
   ```bash
   cp .env.example .env
   ```
   Укажите при необходимости:
   ```env
   PORT=3000
   GEMINI_API_KEY=ваш_ключ_gemini_api
   KMS_MASTER_KEY=ваш_надежный_ключ_длиной_от_32_символов
   ```

4. **Запуск сервера разработки**:
   ```bash
   npm run dev
   ```
   Приложение откроется по адресу `http://localhost:3000`.

## 🐳 6. Развертывание в Docker и Compose

### Запуск через Docker Compose одной командой:

```bash
# Сборка и запуск в фоновом режиме
docker compose up -d --build

# Просмотр логов
docker compose logs -f

# Проверка статуса контейнера
docker compose ps
```

### Ручная сборка и запуск контейнера:

```bash
# Сборка многоэтапного production-образа
docker build -t echosign/voice-inspector:v4.1.0 .

# Запуск с изоляцией прав (non-root)
docker run -d \
  -p 3000:3000 \
  --name echosign-app \
  -e NODE_ENV=production \
  -e KMS_MASTER_KEY=your_secure_production_key \
  echosign/voice-inspector:v4.1.0
```

## 🚀 7. CI/CD Workflows и автоматический деплой

В директории `.github/workflows/` настроены автоматизированные пайплайны GitHub Actions:

- **`.github/workflows/deploy.yml`**:
  1. **🧪 Quality Gate**: Автоматическая проверка типов TypeScript (`tsc --noEmit`), линтинг, сборка frontend/backend и аудит уязвимостей npm.
  2. **🐳 Multi-Arch Docker Build**: Сборка образов для платформ `linux/amd64` и `linux/arm64` с публикацией в GitHub Container Registry (`ghcr.io`).
  3. **☁️ Автоматический деплой**: Развертывание на Google Cloud Run или целевой сервер по SSH/Docker Compose с проверкой healthcheck.
- **`.github/workflows/security.yml`**:
  - Статический анализ безопасности исходного кода **CodeQL SAST**.
  - Сканирование контейнеров и сторонних пакетов сканером **Trivy**.

## 📡 8. Справочник API

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| `POST` | `/api/v1/verify` | Полный фоноскопический анализ Liveness, детекция дипфейка, извлечение водяного знака и сверка с реестром. |
| `POST` | `/api/v1/watermark/embed` | Внедрение подписанного психоакустического водяного знака и сохранение доказательства в реестре. |
| `GET` | `/api/v1/blockchain/blocks` | Получение цепочки блоков с корнями Меркла. |
| `GET` | `/api/v1/blockchain/merkle-proof/:txId` | Получение $O(\log N)$ криптографического доказательства включения в блок. |
| `GET` | `/api/v1/blockchain/stats` | Статистика реестра, статус Polygon L2 анкоринга и высота цепочки. |
| `GET` | `/api/v1/kms/status` | Состояние связки ключей KMS и номер активной эпохи. |
