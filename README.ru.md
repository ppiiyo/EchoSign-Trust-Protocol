## 🎯 1. Для чего нужен проект?

**EchoSign Voice Inspector** — это комплексный инструмент информационной безопасности для оперативной проверки подлинности аудиозаписей, выявления синтезированного искусственным интеллектом голоса (TTS, клоны голоса, Deepfakes), защиты интеллектуальной собственности неслышимыми цифровыми водяными знаками и фиксации истории владения в блокчейн-реестре.

С развитием нейросетей генерации речи (ElevenLabs, VITS, HiFi-GAN, DiffSinger) человеческий слух больше не способен надежно отличать настоящий голос от подделки. EchoSign объединяет **цифровую обработку сигналов (DSP)**, **физическую биометрию голосовых связок человека**, **экспертный ИИ-анализ** и **криптографию** в удобный веб-инструмент.

## ⚡ 2. Какие проблемы решает

| Проблема | Сценарий атаки / Риск | Решение EchoSign |
| :--- | :--- | :--- |
| **Клонирование голоса и Вишинг** | Мошенники клонируют голос директора или родственника для совершения банковских операций или кражи доступов. | **Биометрия Liveness**: Анализирует микрофлуктуации голосового тракта (джиттер, шиммер, соотношение гармоник к шуму HNR) и фазовый спектр нейросетевых вокодеров. |
| **Фальсификация аудиоулик** | Изменение аудиозаписей звонков, допросов или публичных речей с помощью монтажа и генеративных вставок. | **Дерево Меркла и Блокчейн**: Неизменяемая фиксация SHA-256 хешей, временных меток и проверка Inclusion Proofs без раскрытия всей базы. |
| **Нелегальное обучение нейросетей на чужих голосах** | Голосовые базы дикторов и актеров дубляжа скачиваются без ведома авторов для обучения коммерческих AI-моделей. | **Психоакустические водяные знаки DSSS+QIM**: Внедрение неслышимых защитных метаданных в диапазон 1.8–4.6 кГц, выдерживающих сжатие в MP3 и передачу по телефону (G.711). |
| **Ложные срабатывания на студийном вокале** | Автотюн (Auto-Tune / Melodyne) принимается наивными детекторами за синтетический дипфейк. | **Гибридный ансамбль 4 векторов**: Отделяет квантование по музыкальной хроматической сетке от фазового шума диффузионных нейросетей. |

## 🚀 3. Что умеет (Возможности и функционал)

### 🔍 1. Проверка голоса и Детекция Deepfake в реальном времени
- **Мгновенный вердикт**: *Живой голос человека*, *Искусственный голос (AI Deepfake)* или *Подозрительная запись / Обработка*.
- **Измерение физических параметров речи**:
  - **Трекинг основного тона ($F_0$)**: Определение траектории частоты и микромодуляций.
  - **Джиттер (%) и Шиммер (%)**: Оценка естественных микронестабильностей вибрации голосовых связок.
  - **Соотношение Гармоники/Шум (HNR в дБ)**: Выявление неестественно стерильного нейросетевого сигнала.
  - **Анализ фазовой структуры вокодера**: Обнаружение спектральных артефактов гребенчатых фильтров.
- **Запись с микрофона в браузере**: Моментальная проверка живой речи в 1 клик или загрузка файлов (WAV, MP3, M4A, FLAC).
- **Готовые тестовые примеры**: Встроенные образцы настоящего голоса, нейросетевого дипфейка и студийной музыки.

### 🔐 2. Внедрение криптографических водяных знаков
- **Психоакустическая маскировка (ITU-R BS.1387)**: Сигнал маскируется громкими формантами человека, сохраняя $SNR > 40\text{ дБ}$ (полная незаметность для человеческого уха).
- **Широкополосная модуляция DSSS + QIM**: Защита синхропоследовательностями Баркера/Голда.
- **Цифровая подпись HMAC-SHA256**: Защита от подделки и подмены метаданных водяного знака.
- **Стойкость к телефонным фильтрам**: Выдерживает срез частот телефонного кодека G.711 (HPF 300 Гц) и сжатие с потерями.

### ⛓️ 3. Неизменяемый Реестр Подлинности
- **Бинарное Дерево Меркла**: Подтверждение включения транзакции в реестр за время $O(\log N)$ (Inclusion Proofs).
- **Контентная адресация SHA-256**: Контроль целостности аудио на уровне отдельных байтов.
- **Анкоринг в сеть Polygon L2 Rollup**: Периодическая фиксация корня состояния с подписью секвенсера.

### 🧠 4. Экспертные ИИ-Заключения (Gemini 3.7)
- Формирование структурированного текстового судебно-акустического отчёта с объяснением физики голосового тракта и юридическими рекомендациями.
- Автоматический отказоустойчивый переход на локальный детерминированный генератор при сбоях сети или внешних API.

## 💻 6. Как запустить (Пошаговая инструкция)

### Системные требования
- **Node.js**: Версия `18.0.0` или выше
- **Менеджер пакетов**: `npm`, `bun`, `yarn` или `pnpm`
- *(Опционально)* Ключ `GEMINI_API_KEY` для генерации ИИ-отчётов (в проект уже встроен локальный генератор экспертных заключений на случай работы офлайн).

### Шаги установки

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/your-org/echosign-voice-inspector.git
   cd echosign-voice-inspector
   ```

2. **Установите зависимости**:
   ```bash
   npm install
   ```

3. **Настройте переменные окружения**:
   Скопируйте пример конфигурации:
   ```bash
   cp .env.example .env
   ```
   В файле `.env` можно указать свои значения (необязательно для базовой работы):
   ```env
   PORT=3000
   GEMINI_API_KEY=ваш_ключ_gemini_api
   KMS_MASTER_KEY=ваш_секретный_ключ_32_байта
   ```

4. **Запустите режим разработки**:
   ```bash
   npm run dev
   ```
   Откройте браузер по адресу: `http://localhost:3000`.

5. **Сборка и запуск в Production**:
   ```bash
   npm run build
   npm start
   ```

## 📡 7. Справочник API

| Эндпоинт | Метод | Описание |
| :--- | :--- | :--- |
| `/api/v1/verify` | `POST` (multipart) | Полный акустический анализ Liveness, выявление дипфейков, чтение водяного знака и сверка с реестром. |
| `/api/v1/watermark/embed` | `POST` (multipart) | Внедрение психоакустического водяного знака в аудио с регистрацией в блокчейн-реестре. |
| `/api/v1/blockchain/blocks` | `GET` | Получение списка всех зафиксированных записей и корней деревьев Меркла. |
| `/api/v1/blockchain/merkle-proof/:txId` | `GET` | Получение криптографического $O(\log N)$ доказательства включения транзакции. |
| `/api/v1/blockchain/l2-anchor` | `GET` | Просмотр данных нотаризации в сети Polygon L2 Rollup. |
| `/api/v1/kms/status` | `GET` | Просмотр статуса активных ключей шифрования и текущей эпохи KMS. |

## 🔒 8. Криптографические гарантии

- **Стеганография**: Модуляция по стандарту ITU-R BS.1387 гарантирует отсутствие слышимых искажений ($SNR > 40\text{ дБ}$).
- **Защита от модификаций**: Подписи HMAC-SHA256 вычисляются на основе изолированных доменных ключей (PBKDF2/HKDF).
- **Ротация ключей**: Встроенный KMS позволяет проводить бесшовную ротацию эпох ключей без утраты возможности проверки старых подписей.
- **Гарантия неизменности**: Деревья Меркла гарантируют, что ни одна запись не может быть отредактирована задним числом.
